# manuscript-proofreading-skill

Agent skill for final-stage proofreading of accepted medical manuscripts
(Annals of Coloproctology house style by default). Works in Claude, OpenAI
Codex, and — via a Custom GPT — ChatGPT.

See [`manuscript-proofreading/README.md`](manuscript-proofreading/README.md)
for installation on each platform.

Package for Claude.ai upload: `zip -r manuscript-proofreading.skill manuscript-proofreading`
